## 启动与停止

前台运行（先停止后台服务，避免争用摄像头和 5000 端口）：

```bash
cd /home/hyz/smart_desk
systemctl --user stop smart-desk.service
.venv-pi/bin/python -u main.py --headless
```

`--headless` 关闭本地 OpenCV 窗口，识别、网页视频和控制仍运行。前台按 Ctrl+C 正常释放设备。省略该参数可保留桌面窗口与原有键盘操作。

后台服务：

```bash
systemctl --user start smart-desk.service
systemctl --user status smart-desk.service --no-pager
systemctl --user stop smart-desk.service
systemctl --user restart smart-desk.service
```

网页地址：[http://192.168.111.233:5000](http://192.168.111.233:5000)。IP 变化后使用实际 IP。

服务模板是 `deploy/smart-desk.service`，面向项目放在当前用户 `~/smart_desk` 的部署。首次安装模板：

```bash
mkdir -p ~/.config/systemd/user
cp deploy/smart-desk.service ~/.config/systemd/user/smart-desk.service
systemctl --user daemon-reload
systemctl --user enable --now smart-desk.service
```

这是用户服务，`enable` 表示随用户服务管理器启动；没有配置 linger 或登录机制时，不能保证开机后尚未登录就运行。本次不通过重启树莓派来验证。服务停止使用 SIGINT，使主程序保存当前会话并释放摄像头；异常退出会在约 5 秒后重试。

查看日志：

```bash
journalctl --user -u smart-desk.service -n 80 --no-pager
```

如果系统提示无用户日志，可以改用 `systemctl --user status smart-desk.service --no-pager` 查看最近输出，或使用已在本机验证的 `journalctl _SYSTEMD_USER_UNIT=smart-desk.service -n 80 --no-pager`。当前设备的 journal 查询对用户日志的可见性存在差异，不应将“无日志条目”误判为服务未运行。

## 复测模型与摄像头

独占摄像头运行下面的有限帧数测试；它不会打开窗口或保存摄像头画面：

```bash
cd /home/hyz/smart_desk
systemctl --user stop smart-desk.service
.venv-pi/bin/python -u -m tests.manual.test_pi_runtime --frames 30
systemctl --user start smart-desk.service
```

测试会初始化真实模型、推理空图像、采集并推理指定帧数，最后释放设备。`frames_with_features=0` 可能表示无人或头肩不清晰，不代表模型未执行；需要人员正面入镜后进一步测试识别和校准。

2026-11-22 首次成功记录：30 帧完成，模型初始化约 0.326 秒，采集与推理约 7.0 FPS，平均推理约 115.4 毫秒；这不是准确率或长期性能承诺。仓库的 `tests/assets/test_frame.jpg` 已成功提取有效头肩特征。

## 重建依赖环境

本机的 uv 工具位于 `~/.local/share/smart-desk/bootstrap/bin/uv`，版本 0.13.9；独立 Python 位于 `~/.local/share/smart-desk/python`。原始文件备份位于 `~/.local/share/smart-desk/backups/20261122-191923/`。

对尚未创建 `.venv-pi` 的部署，可以在已安装该 uv 工具后执行：

```bash
cd /home/hyz/smart_desk
export UV_PYTHON_INSTALL_DIR="$HOME/.local/share/smart-desk/python"
SMART_DESK_UV="$HOME/.local/share/smart-desk/bootstrap/bin/uv"
"$SMART_DESK_UV" python install 3.11.18
"$SMART_DESK_UV" venv --python 3.11.18 .venv-pi
"$SMART_DESK_UV" pip sync --python .venv-pi/bin/python --only-binary=:all: --require-hashes --default-index https://mirrors.aliyun.com/pypi/simple requirements-pi.lock
"$SMART_DESK_UV" pip check --python .venv-pi/bin/python
```

同步依赖会按锁定文件调整指定环境，应在服务停止时操作。锁定文件从官方 PyPI 元数据生成，镜像下载需通过锁定的哈希校验；不需要升级系统 Python或覆盖旧 `.venv`。uv 管理 Python 的方法见[官方说明](https://docs.astral.sh/uv/guides/install-python/)。
